## Pourquoi on a choisi ses tables

Pourquoi on a choisi ces tables

Nous avons choisi ces tables parce qu'elles sont nécessaires pour gérer les élèves et leurs inscriptions scolaires.



## Les entités

Les principales entités identifiées dans notre système sont :

- Élève : représente l’élève inscrit dans l’établissement.
- AnnéeScolaire : représente l’année scolaire concernée par l’inscription de l’élève.
- Inscription : représente l’inscription d’un élève pour une année scolaire et une classe donnée.
- Classe : représente une classe dans laquelle les élèves sont affectés.
Établissement** : représente l’établissement scolaire.
* **Responsable** : représente la personne responsable d’un ou plusieurs élèves.
* **Rôle** : représente le rôle d’un utilisateur dans le système.
* **Statut** : représente l’état d’une inscription ou d’un élément du système.
